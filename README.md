SAFE SYSTEM — FULL VERSION (RIDVAN AREA)
DE / ENG / TR — Combined Explanation

============================================================
DEUTSCH (DE)
============================================================

SAFE ist ein Schutzmodus für sensible Bereiche. 
SAFE führt nichts automatisch aus, verändert nichts, startet nichts.
SAFE schützt Menschen, die unsicher, nervös oder ängstlich sind.

SAFE arbeitet mit drei Farben:
GRÜN  = alles sicher, keine Aktion
GELB  = Unsicherheit erkannt, System wartet
ROT   = Risiko erkannt, Aktion gestoppt

Grundzustand:
STATE = GREEN
SAFE  = ON
ACTION = BLOCKED

Wenn jemand unsicher ist:
STATE = YELLOW
ACTION = PAUSED
REASON = "Unsicherheit erkannt"

Wenn Risiko erkannt wird:
STATE = RED
ACTION = STOPPED
REASON = "Risiko erkannt"

Counter-System:
SAFE_COUNT  = wie oft SAFE aktiv wurde
CHECK_COUNT = wie oft GELB ausgelöst wurde
STOP_COUNT  = wie oft ROT ausgelöst wurde

Admin-Verhalten:
ADMIN_REQUIRED = FALSE
ADMIN_ALLOWED  = TRUE
ADMIN_ACTION   = "bewusst"
Wenn jemand Admin nutzt, dann absichtlich und wissend.

SAFE speichert keine Daten.
SAFE ist freundlich, ruhig und neutral.
SAFE schützt durch Ruhe, nicht durch Druck.

============================================================
ENGLISH (ENG)
============================================================

SAFE is a protection mode for sensitive areas.
SAFE does not run anything automatically, does not change anything,
does not execute commands without permission.

SAFE uses three colors:
GREEN = everything safe, no action
YELLOW = uncertainty detected, system pauses
RED = risk detected, action stopped

Default state:
STATE = GREEN
SAFE  = ON
ACTION = BLOCKED

If the user is unsure:
STATE = YELLOW
ACTION = PAUSED
REASON = "Uncertainty detected"

If a risk is detected:
STATE = RED
ACTION = STOPPED
REASON = "Risk detected"

Counter system:
SAFE_COUNT  = how many times SAFE was active
CHECK_COUNT = how many times YELLOW was triggered
STOP_COUNT  = how many times RED was triggered

Admin behavior:
ADMIN_REQUIRED = FALSE
ADMIN_ALLOWED  = TRUE
ADMIN_ACTION   = "intentional"
If someone uses admin, they do it knowingly and intentionally.

SAFE saves no data.
SAFE is friendly, calm and neutral.
SAFE protects through stability, not pressure.

TÜRKÇE (TR)
============================================================

SAFE hassas alanlar için bir koruma modudur.
SAFE hiçbir şeyi otomatik çalıştırmaz, hiçbir ayarı değiştirmez,
hiçbir komutu izinsiz yürütmez.

SAFE üç renk ile çalışır:
YEŞİL = her şey güvenli, işlem yok
SARI  = kararsızlık algılandı, sistem bekler
KIRMIZI = risk algılandı, işlem durduruldu

Varsayılan durum:
STATE = GREEN
SAFE  = ON
ACTION = BLOCKED

Kullanıcı kararsızsa:
STATE = YELLOW
ACTION = PAUSED
REASON = "Kararsızlık algılandı"

Risk algılanırsa:
STATE = RED
ACTION = STOPPED
REASON = "Risk algılandı"

Sayaç sistemi:
SAFE_COUNT  = SAFE kaç kere aktif oldu
CHECK_COUNT = SARI kaç kere tetiklendi
STOP_COUNT  = KIRMIZI kaç kere tetiklendi

Admin davranışı:
ADMIN_REQUIRED = FALSE
ADMIN_ALLOWED  = TRUE
ADMIN_ACTION   = "bilinçli"
Biri admin kullanırsa, bunu bilerek ve isteyerek yapar.

SAFE veri kaydetmez.
SAFE her zaman sakin, dostça ve nötrdür.
SAFE baskıyla değil, sakinlikle korur.
